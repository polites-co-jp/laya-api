# ポート台帳（写し）

正本は Notion「ポート管理」データベース。変更するときは両方を更新する。

- 予約レンジ: **22300-22399**（2026-10-02 採番）
- 定義: [laya-api-containers/docker-compose.yml](../laya-api-containers/docker-compose.yml)

| ポート | サービス | コンテナ内部 | 既定バインド | 用途 |
|---|---|---|---|---|
| 22300 | api | 8080 | 127.0.0.1（`API_HOST_BIND` で変更可） | 署名を検証して Laya へ中継する API |
| 22301 | chat | 3000 | 127.0.0.1（固定） | 開発用の動作確認チャット（profile `dev` のみ） |
| —（非公開） | laya | 8000 | ホスト公開なし | Laya 本体（laya-serve）。compose 内のネットワークからのみ到達できる |
| 22302-22399 | — | — | — | 予備 |

- ホスト公開ポートは `.env` の `API_HOST_PORT` / `CHAT_HOST_PORT` で上書きできるが、22300-22399 の範囲内に限る。
- laya は認証を持たないのでホストへ公開しない。外からは必ず api（署名認証）を経由する。
- chat は署名を代行するため、届いた人は誰でも API を使える。ホスト外へ公開しない。
- VPS では Docker の公開ポートが ufw をバイパスするため、`API_HOST_BIND=0.0.0.0` にするときはリバースプロキシや外部ファイアウォールで守る。
