# 誹謗中傷判定の検証

掲示板・SNS の投稿200件を Laya で「誹謗中傷にあたる / あたらない / どちらとも言えない」に分類し、正解ラベルと比べて精度を測る。
方針は [決定事項 D-09](decisions.md#d-09-誹謗中傷判定の検証は裁判例データセットで行う2026-10-07)、スクリプトと実行手順は [apps/defamation-eval](../apps/defamation-eval/README.md)。

## 判定基準

プラットフォーム（SNS・掲示板の運営）のモデレーション基準に寄せる。法的に名誉毀損・侮辱が成立するかは問わない。

### 判定の単位

- 投稿本文だけを見て判定する。前後の投稿（データセットの `context`）は見ない。Laya に渡すのも本文だけなので、条件をそろえる。
- `[P-ind]`・`[D-group]`・`[IDinfo]` などはデータセットが匿名化した人名・団体名で、特定の相手として扱う。`[URL]` は URL。

### 相手

誹謗中傷は「特定の、または特定できる相手」への攻撃に限る。

- 相手に含める: 個人、店・会社・団体、匿名化記号、「この人」「こいつ」「ここの社長」など本文から特定の相手を指すと読めるもの、スレッドの相手への呼びかけ（「お前」）。
  主語が省略されていても、特定の人を指して侮辱していると読めるもの（「ほんと救いようのないクズだよな」）も含める。
- 相手に含めない: 国籍・民族・政党支持者・世代などの広い集団、相手を指さない一般論や独り言。差別的・攻撃的でも、広い集団へのものはこの検証では「誹謗中傷にあたらない」とする（差別表現の判定は別の問題として扱う）。

### 3つの区分

| 区分 | ラベル | 基準 |
|---|---|---|
| 誹謗中傷にあたる | `defamatory` | 相手に向けて、次のどれかをしている。(a) 侮辱・人格攻撃（「バカ」「キモい」「ゴミ」「基地外」「死ね」など）、(b) 根拠を示さずに犯罪・不正・反社会的な行為や悪評を断定し、評価を下げる（「詐欺師」「横領している」「反社」など）、(c) 脅迫・危害の示唆、(d) 攻撃や嫌がらせを目的とした私生活の暴露 |
| 誹謗中傷にあたらない | `not_defamatory` | 相手がいない、好意的・中立、または根拠や具体的な経験に基づく批判・感想で、人格攻撃や悪評の断定を含まない |
| どちらとも言えない | `uncertain` | 本文だけでは相手・意図・真偽が判断できない（皮肉・隠語・内輪の話）、または否定的だが攻撃と批判の境界にある（強めの不満や評価で、侮辱語も悪評の断定もない） |

### 境界の例（架空の文）

| 文 | 区分 | 理由 |
|---|---|---|
| [P-ind]って本当に頭おかしいよな | defamatory | 特定の相手への侮辱 |
| [D-group]の社長、裏で客の金を使い込んでるらしい | defamatory | 根拠を示さない不正の断定（伝聞の形でも評価を下げる） |
| この店、注文から1時間待たされた。二度と行かない | not_defamatory | 具体的な経験に基づく不満 |
| 〇〇党の支持者は頭が悪い | not_defamatory | 広い集団への攻撃で、特定の相手ではない |
| あの人の対応はちょっとどうかと思う | uncertain | 否定的だが攻撃と批判の境界 |
| この店の店員、しつこく勧誘してくるから気をつけて | uncertain | 経験に基づく注意喚起とも、悪評の拡散とも読める |
| またあいつか、わかってたけど | uncertain | 文脈がないと意図が分からない |

### Laya への質問

上の基準を短くして `choice` 型の質問1つにした。実際に送る内容は [laya_question.json](../apps/defamation-eval/laya_question.json)。
`probabilities` の3つの値（合計1）を、CSV の `p_defamatory`・`p_not_defamatory`・`p_uncertain` にする。

## 結果（2026-10-07、正解ラベルは人の確認前）

数値の全体は [report.md](../apps/defamation-eval/report.md)。Laya は `laya[serve]==0.3.28` の multilingual チェックポイント（CPU）。

- **Laya はほとんど「当たらない」と答える。** 最も確率の高い選択肢は、200件中185件が「当たらない」、15件が「当たる」、「どちらとも言えない」は0件だった。正答率は55.5%で、常に「当たらない」と答えた場合（49.0%）をわずかに上回る程度。
- **「当たる」と答えたときはほぼ正しい。** 「当たる」15件のうち14件が正解（適合率93.3%）。ただし誹謗中傷66件のうち拾えたのは14件（再現率21.2%）。
- **確率には順位付けの手がかりがある。** `p_defamatory` の ROC AUC は0.691。閾値を0.5ではなく0.2に下げると、「当たる」の適合率52.9%・再現率56.1%（F1 0.544）で、この中で最もよい釣り合いになる。
- **「どちらとも言えない」の確率は低くまとまる。** `p_uncertain` は最大でも0.36で、正解が「どちらとも言えない」の投稿でも平均0.14。3つ目の選択肢としてはほぼ機能していない。
- **取りこぼしの傾向**（`data/05_evaluation.csv` で `p_defamatory` が低い順に見たもの）: 侮辱語を使わない形の攻撃、つまり脅迫の言い回し・根拠のない犯罪や不正の断定・噂の拡散・容姿や障害をあげつらう表現は、`p_defamatory` が0.1未満になりやすい。上位に来るのは「死ね」「キモい」「生ゴミ」のような明示的な侮辱語を含む投稿。

この結果からは、Laya の確率を誹謗中傷の自動判定にそのまま使うのは難しい。一方で、`p_defamatory` の高い投稿を優先して人が見る、という並べ替えには使える余地がある。
質問の書き方（`laya_question.json`）を変えると結果が変わりうるが、今回は1通りだけを試した。
